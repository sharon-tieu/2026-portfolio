About me

Hi, I'm Sharon.

I started out writing documentation, which meant years of watching the gap between how software is built and how people try to use it. Design was the obvious next step: fix the screen so the manual gets shorter.

I'm Chinese-American and moved to Manhattan for my role at JPMorgan Chase. Outside work I'm usually out with friends or finding a new spot somewhere in the city.

Core values

What I design by

Clarity first

I started as a technical writer, so I care a lot about making complicated things read clearly. If it needs a manual, the design isn't done.

Close the gap

I've spent years between how software is built and how people try to use it. I design for that space, with engineers and users in the same room.

Keep going

Technical writer to designer, Designlab to JPMorgan, and now trying every cafe in New York. I stay curious and keep learning by doing.
